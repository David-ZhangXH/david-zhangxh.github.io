# Stage 2 — The Desk (3D Hub) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The cinematic 3D desk hub from spec §2 — seven interactive hotspots with content cards, a skippable intro, mouse parallax, rain and steam, mounted on top of the Stage-1 classic page with a permanent "☰ classic site" escape hatch and hard fallbacks.

**Architecture:** The desk is a lazy-loaded chunk (`src/desk/`) that mounts over the classic page when WebGL is available and `prefers-reduced-motion` is off. Pure logic (state machine, card HTML builders, birthday formatting) is unit-tested; the three.js scene (primitives + canvas textures, no external 3D assets) is verified by a Playwright screenshot/e2e loop. Cards are DOM overlays, so all content stays selectable, accessible, and testable.

**Tech Stack:** three.js (only runtime dep), Vitest, Playwright (SwiftShader WebGL in headless).

**Plan 2 of 5.** Spec: `docs/superpowers/specs/2026-08-07-david-world-design.md` §2 (hub), §5 (classic toggle), §7 (perf/persistence).

**Stage-2 scope notes:** Monitor and handheld hotspots open *teaser cards* ("the galaxy is forming" / "the handheld is asleep") — the real transitions arrive in Stages 3–4. Ambience *audio* is Stage 5; the music box card ships now with a placeholder playlist. Heart steam is visual-only.

## File structure

```
src/core/html.js            # esc() + LINK_LABELS shared with classic (extracted)
src/core/capability.js      # webglAvailable(), reducedMotion()
src/desk/state.js           # intro/idle/focus state machine (pure, tested)
src/desk/cards.js           # pure HTML builders for all 7 cards (tested)
src/desk/poses.js           # hotspot -> camera pose table (data)
src/desk/scene.js           # renderer, camera, lights, resize, rAF loop, pause
src/desk/furniture.js       # buildDesk(): all objects + hotspot registry
src/desk/effects.js         # rain, steam (+heart mode), screen star texture
src/desk/index.js           # mountDesk()/unmountDesk(): glue, raycast, tweens, overlay
src/desk/desk.css           # overlay cards, classic-toggle button, veil
content/playlist.json       # work-music list (placeholder entries)
tests/cards.test.js
tests/deskState.test.js
tests/playlist.test.js
scripts/e2e-desk.mjs        # headless WebGL e2e + screenshots
```

`main.js` gains ~20 lines: capability check → lazy-import desk → mount, with 5s guard and toggle buttons both ways. Classic page and Stage-1 tests remain untouched (except esc() extraction refactor).
